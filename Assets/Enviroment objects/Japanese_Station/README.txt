Stylized Low Poly Japanese Station

Thank you for using Stylized Low Poly Japanese Station!

PACKAGE CONTENTS
- 20 ready-to-use prefabs
- Modular station environment pieces
- Railway and platform modules
- Benches, signs, trash cans, ticket machine and other props
- 1 optimized 2048x2048 color atlas
- Demo scene included

USAGE
Drag and drop the prefabs from the Prefabs folder into your scene.
Modular pieces can be combined to create different station layouts.

RENDER PIPELINE
Created and tested using the Built-in Render Pipeline.

FOLDERS
Materials - Materials used by the assets
Models - Source 3D models
Prefabs - Ready-to-use prefabs
Scenes - Demo scene
Textures - Texture atlas
